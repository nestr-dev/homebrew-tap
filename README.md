# nestr-dev/homebrew-tap

Homebrew tap for the [Nestr CLI](https://github.com/nestr-dev/nestr-cli) (`nestr`).

```sh
brew install nestr-dev/tap/nestr-cli
nestr --help
```

The formula installs a prebuilt, cosign-signed release binary (no compilation).
`Formula/nestr-cli.rb` is **auto-generated** by the nestr-cli release workflow on
each `v*` tag — don't hand-edit it.
